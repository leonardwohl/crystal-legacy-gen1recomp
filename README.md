# Crystal Legacy for gen1recomp

WIP collection of [gen1recomp](https://github.com/bryanthaboi/gen1recomp) mods,
based on the fantastic work by the
[Crystal Legacy Team](https://github.com/cRz-Shadows/Pokemon_Crystal_Legacy).

**Install:** in gen1recomp, go to **MODS → Find mods**, add the source
`leonardwohl/crystal-legacy-gen1recomp`, and pick the mods you want. Or grab
the zips from [Releases](https://github.com/leonardwohl/crystal-legacy-gen1recomp/releases).
