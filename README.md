# Crystal Legacy for gen1recomp

An unofficial mod that ports [Pokémon Crystal Legacy](https://github.com/cRz-Shadows/Pokemon_Crystal_Legacy)
to [gen1recomp](https://github.com/bryanthaboi/gen1recomp)'s Crystal mode.

Crystal Legacy is a ROM hack by TheSmithPlays and cRz Shadows. All of its design
credit belongs to them and the people listed in its README. This repository
only translates their data into gen1recomp's mod format.

**Status: early (0.1.0).** The data side of Crystal Legacy is ported. Story,
map script and engine features are not yet; see [What's ported](#whats-ported).
It has passed automated checks but has **not been play-tested yet**.

## Install

1. Use gen1recomp **0.4.x** with a US Pokémon Crystal ROM (1.0 or 1.1) imported.
2. Zip the contents of the `mod/` folder, so that `manifest.json` is at the
   root of the zip (or grab a zip from Releases once there are some).
3. In gen1recomp, open **MODS → Import mod .zip** and pick the zip.
4. Enable **Crystal Legacy** for Crystal and start a **new game**. Changes to
   wild Pokémon and trainers apply right away to existing saves, but the mod is
   balanced around a fresh run.

The mod only loads on Crystal (`"games": ["crystal"]`).

## What's ported

The converter writes only what Crystal Legacy changed, so everything else comes
from gen1recomp's own import of your ROM. The current counts are in
[docs/generated-changes.md](docs/generated-changes.md).

| Ported | Not ported yet |
|---|---|
| Base stats, types, catch rates | Story and Team Rocket script changes, new events and NPCs |
| Level-up learnsets, TM/HM and tutor compatibility, egg moves | Gym leader / Elite Four rematches (the teams are in, but no script starts the battles) |
| Evolutions | New trainer classes (Giovanni, Archer, …) |
| Faster egg hatching (step cycles quartered) | Hard Mode, Hardcore Mode and level caps |
| Move power, accuracy, PP, type and effect changes | Running, Exp. Share change, Set mode battle types |
| Ghost moves special, Dark moves physical | New Pokédex area pages and colours |
| Every changed trainer party, including held items and moves | Fossil items (Old Amber, Dome and Helix Fossil) and new shops |
| Custom DVs and stat exp on Elite Four and rematch teams | Headbutt tree and fleeing-Pokémon tables, in-game trades |
| Wild grass and water encounters (morning/day/night) | Move description text, new sprites and other graphics |
| Shop stock and item prices | Odd Egg and happiness tweaks |

Most of the right-hand column needs scripting work in gen1recomp's Crystal
script engine rather than data patches. [docs/porting-notes.md](docs/porting-notes.md)
has the details.

## Rebuilding the mod

`mod/main.lua` is generated, so edit the converter instead of the file.

You need Python 3, and for the tests LuaJIT and a gen1recomp checkout.

```bash
git clone https://github.com/cRz-Shadows/Pokemon_Crystal_Legacy legacy
git clone https://github.com/pret/pokecrystal pokecrystal
git -C pokecrystal worktree add ../base 82e315e48
python3 tools/convert.py --base base --legacy legacy
```

`82e315e48` is the pokecrystal commit Crystal Legacy was forked from: 1,850 of
its 2,477 `.asm` files match that commit byte for byte, more than any other.
Diffing against the right base is what keeps pokecrystal's own later
refactors out of the mod.

To test it, run the following. It rebuilds the fixture, runs gen1recomp's
`modkit` checks, and loads the mod through gen1recomp's real mod loader:

```bash
tools/test.sh path/to/gen1recomp path/to/base
```

The fixture (`tests/fixture_crystal.lua`, regenerated by `test.sh`) is built from the disassembly, not from a
ROM.
