# Legacy: Menu Icons

Crystal Legacy's per-species party menu icons and colours. Bring your own icons: copy Crystal Legacy's gfx/icons folder into this mod's folder as icons/.

## What it changes

- Crystal Legacy's party menu icons: one icon per species, coloured with Legacy's per-species palette (and its shiny palette)
- **The icons are not included.** Copy Crystal Legacy's `gfx/icons` folder into this mod's folder as `icons/` (so `icons/bulbasaur.png` and so on). Species without a file keep gen1recomp's normal icon
- 251 species mapped to Legacy's icon files and palettes

Games: crystal. Needs gen1recomp >=0.4.0 <0.5.0.
